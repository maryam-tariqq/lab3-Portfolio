# Maryam Tariq - Personal Portfolio

A multi-page personal portfolio website built with plain **HTML** and **CSS** for a lab in my Web Engineering course


`index.html`: Home / introduction with floated profile picture. 

`hobbies.html`: Hobby cards laid out with float   

`skills.html`: Technical, language and other skills. 

`gallery.html`: Image gallery (5 images) arranged with float and clear. 

`contact.html`: Contact details and message form
